# My Portfolio Website

A simple three-page portfolio website created for a Git and GitHub assignment.

## Pages
- `index.html` — Home page
- `about.html` — About page
- `contact.html` — Contact page

## Technologies
- HTML
- CSS

## How to view
Open `index.html` in a web browser. Use the navigation links to move between pages.

Note: The contact form is a front-end demonstration and does not send messages to an inbox.
